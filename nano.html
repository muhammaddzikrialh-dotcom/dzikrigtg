🌐 Basic Cisco Commands

Panduan dasar Cisco IOS untuk pemula

Catatan: Perintah di bawah dapat digunakan untuk latihan di Cisco Packet Tracer atau perangkat Cisco yang mendukung Cisco IOS.

1. Perintah Dasar

enable

Masuk ke privileged EXEC mode.

disable

Kembali dari privileged mode ke user EXEC mode.

configure terminal

Masuk ke global configuration mode.

exit

Kembali satu level konfigurasi.

end

Kembali langsung ke privileged EXEC mode.

2. Mengatur Hostname

enable

Masuk privileged mode.

configure terminal

Masuk konfigurasi global.

hostname R1

Mengubah nama perangkat menjadi R1.

3. Konfigurasi IP Address

interface gigabitEthernet 0/0

Masuk ke interface GigabitEthernet 0/0.

ip address 192.168.1.1 255.255.255.0

Memberikan IP address pada interface.

no shutdown

Mengaktifkan interface.

shutdown

Menonaktifkan interface.

4. Perintah Show

show running-config

Melihat konfigurasi yang sedang berjalan.

show startup-config

Melihat konfigurasi yang tersimpan.

show ip interface brief

Melihat status dan IP address interface.

show version

Melihat informasi perangkat dan IOS.

show interfaces

Melihat informasi detail interface.

5. Menyimpan Konfigurasi

copy running-config startup-config

Menyimpan konfigurasi agar tidak hilang setelah restart.

write memory

Alternatif untuk menyimpan konfigurasi pada beberapa IOS.

6. Password Dasar

enable secret cisco

Membuat password untuk privileged EXEC mode.

line console 0

Masuk ke konfigurasi console.

password cisco

Memberikan password pada line console.

login

Mengaktifkan pemeriksaan password.

7. Testing Koneksi

ping 192.168.1.2

Menguji koneksi ke perangkat dengan IP tertentu.

traceroute 192.168.1.2

Melihat jalur paket menuju tujuan.

8. DHCP Server Dasar

ip dhcp pool LAN

Membuat DHCP pool bernama LAN.

network 192.168.1.0 255.255.255.0

Menentukan network yang digunakan DHCP.

default-router 192.168.1.1

Menentukan gateway untuk client.

dns-server 8.8.8.8

Menentukan DNS server untuk client.

ip dhcp excluded-address 192.168.1.1 192.168.1.10

Mengecualikan IP tertentu dari DHCP.

9. VLAN Dasar

vlan 10

Membuat VLAN 10.

name ADMIN

Memberikan nama ADMIN pada VLAN.

interface fastEthernet 0/1

Memilih interface FastEthernet 0/1.

switchport mode access

Mengatur port menjadi access.

switchport access vlan 10

Memasukkan port ke VLAN 10.

10. Static Routing

ip route 192.168.2.0 255.255.255.0 192.168.1.2

Membuat static route menuju network 192.168.2.0/24.

11. Reset Konfigurasi

erase startup-config

Menghapus konfigurasi startup.

reload

Restart perangkat.
